# Commishly Marketing Site

Marketing and landing page for Commishly - Commission Management for Food & Beverage Brands.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Domain:** getcommishly.com / www.getcommishly.com

## Local Development

```bash
# Install dependencies
npm install

# Run development server (port 3001)
npm run dev

# Build for production
npm run build
```

Visit http://localhost:3001

## Deployment

This site is deployed to Vercel and configured for:
- `getcommishly.com` (root domain)
- `www.getcommishly.com` (www subdomain)

The main application is hosted separately at `app.getcommishly.com`.
