# Contributing

Thank you for your interest in contributing to the Commishly marketing site!

## Reporting Issues

If you find a bug or have a suggestion:

1. Check if the issue already exists
2. Open a new issue with a clear description
3. Include steps to reproduce for bugs

## Contributing Code

This repository contains the public marketing site for Commishly. We welcome improvements to:

- Documentation and copy corrections
- Accessibility enhancements
- Performance optimizations
- Bug fixes

### Process

1. Fork the repository
2. Create a feature branch: `git checkout -b fix/your-fix`
3. Make your changes with clear commit messages
4. Ensure the build passes: `npm run build`
5. Submit a pull request with a description of your changes

### Code Standards

- TypeScript with strict mode
- Follow existing code style (ESLint + Prettier)
- Test your changes locally before submitting

## Security

If you discover a security vulnerability, please see [SECURITY.md](./SECURITY.md) for responsible disclosure instructions. **Do not open public issues for security reports.**

## Questions?

Feel free to open an issue for questions or email hello@getcommishly.com
