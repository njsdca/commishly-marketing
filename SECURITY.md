# Security

## Reporting Security Issues

If you believe you've found a security vulnerability in the Commishly marketing site, please email us at:

**security@getcommishly.com**

Please do not open public issues for security reports.

## Security Measures

- Environment variables are stored securely and never committed to the repository
- Dependencies are automatically scanned and updated via Dependabot
- CodeQL analysis runs on every push and pull request
- Email API keys are server-side only

## Responsible Disclosure

We appreciate your efforts to responsibly disclose your findings and will make every effort to acknowledge your contributions.

Thank you for helping keep Commishly and our users safe!
